# Northeast Watch

> A digital current-affairs platform covering security, development, society, youth and achievements across Northeast India.

**Northeast Watch** is a React + Vite companion platform developed alongside the e-magazine:

**“Securing the Northeast: Indian Army’s Role in Stability, Peace & National Security”**

The platform organizes verified current-affairs stories across the eight states of Northeast India and provides transparent source and verification information for every article.

---

## 🎯 Project Overview

Northeast Watch was designed as a lightweight digital companion to a 50-page e-magazine focused on the Northeast region.

The platform provides:

- 📰 Curated current-affairs articles
- 🔎 Article search
- 🗂️ Category-based filtering
- 🗺️ Regional/state-based organization
- ✅ Article verification status
- 🔗 Direct source references
- 📚 Supporting sources
- 💡 Article-selection rationale
- 📱 Responsive interface
- 📖 Article verification modal

The application is intentionally frontend-focused, making it simple to deploy and maintain.

## ✨ Key Features

### 🔎 Search & Filtering
Users can search articles and filter them by editorial category.

### 📰 Article Discovery
Each article contains structured information including:

- Headline
- Publication date
- Category
- Region
- Summary
- Tags
- Source
- Verification status

### ✅ Verification Information
Articles include information explaining how and why they were selected.

### 🔗 Source Transparency
Each article provides a direct source reference so readers can independently inspect the underlying reporting.

### 📚 Supporting Sources
Where applicable, articles can include additional supporting references.

### 📱 Responsive Design
The interface is designed to work across desktop, tablet and mobile screen sizes.

### 🎨 Editorial UI
The visual design follows a professional current-affairs / defence-publication aesthetic while keeping the interface lightweight.

---

## 🛡️ Editorial & Verification Methodology

Northeast Watch follows a structured approach when selecting articles.

Before an article is included, the following factors are considered:

1. Publication date
2. Original source
3. Relevance to the assigned theme
4. Factual consistency
5. Direct source URL
6. Reason for selecting the article

The website is intended to complement the 50-page e-magazine rather than replace it.

The e-magazine remains the primary editorial submission, while Northeast Watch acts as a digital research, source-verification and article-discovery companion.
